# 《模拟中世纪领主·铁冠之路》纵切片设计

## 一句话

父亲远征失败后，玩家继承渡鸦堡：一座漏雨的城堡、四个贫穷村庄、一笔王室欠税，以及几名并不完全认可新主人的家臣。

## 核心循环

经营产出 → 养活人口和军队 → 出兵夺地 → 处理战损与战后统治 → 新领地扩大产出和边境 → 更大的冬季、功臣与反攻压力。

战争与经营共用同一批资源：

- 军队分成长矛兵、弓箭手和披甲骑士。长矛兵便宜且承担主要战损，弓手适合密林、山地与河网，骑士在平原最强、冬季最弱。
- 三类军队分别增加粮食与军饷消耗，兵营会提高部分兵种的单次征募量。
- 远征在开战前扣除2点行动和军粮；战后需要2—3季整补，不能逐季连续滚雪球。
- 夺城后必须从野战军中抽调驻军，玩家需要在扩张速度和可用兵力间取舍。
- 每次远征与伤亡都会累积战争疲劳，持续压低战力和全部直辖产出；不出征或安排休整可以恢复。
- 新领地经历两季战损，不能立刻提供满额产出。
- 每块领地可持续执行常例、轻徭、加税或军屯政策，用短期产出交换稳定、民心或守军。
- 分封可提高家臣忠诚与领地稳定，但会减少直辖收入。
- 直辖保留全部收入，却会让高功勋家臣积累怨气。
- 敌军守军会随年份和玩家扩张增长，也可以反攻并夺回边境领地，不是单向涂色。
- 连续饥荒、长期重债、民心崩解或彻底失去军队会结束统治；失败不是只有丢掉祖堡一种。

## 战役结构

战役分为行军接敌、两军交锋、胜负将分三段。每段单独判定势头和伤亡，人物根据自身能力与特性提出方案。第二段结束后，玩家可以在决胜阶段选择撤退止损。

攻守比只决定基础盘面；兵种编成、地形、季节、方略、战争疲劳、随军人物、军心、训练和三次临场选择共同决定结果。弓手达到最低人数后可执行轮射，骑士达到最低人数后可执行冲阵。战役会话写入本地存档，刷新页面后仍需继续作战。

## 纵切片边界

当前版本已经形成可从继承玩到统一的完整闭环，地图规模控制在7领、7名核心人物、48季度。王冠谷需控制其余六领且进入第7年后开放，以保证事件、经营与家臣政治都有实际展开时间。后续适合扩展但不应在基础闭环验证前加入的内容包括：婚姻继承、宗教派系、长期围城、海上贸易与王国外交。
