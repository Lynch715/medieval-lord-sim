# 立绘生成说明

本项目7张人物立绘均使用内置 ImageGen 单独生成，再转为768像素宽的 WebP 接入游戏。PNG原图保留在生成记录中，项目运行使用轻量版本。

## 统一视觉提示

- 用途：中世纪领主模拟游戏竖版人物立绘
- 画面：2:3竖构图，腰部以上，人物居中，头部与双手完整入镜
- 风格：写实数字油画、电影自然主义、轻微笔触质感、符合中世纪晚期的服装材质
- 光线：冷蓝灰窗光与克制的暖色火光轮廓
- 色彩：石板灰、铁灰、旧棕、暗酒红，低饱和
- 材质：磨损羊毛、刮痕皮革、锁子甲、旧石墙、真实皮肤
- 禁止：文字、水印、边框、王冠、浮夸奇幻盔甲、现代妆容、动漫感、光亮cosplay质感
