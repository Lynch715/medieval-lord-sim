# 模拟中世纪领主 · 铁冠之路

原创架空中世纪领主模拟游戏。玩家继承破败的渡鸦堡，通过四季经营、家臣政治和分阶段战争统一北境七领。

## 已实现

- 12年、48季度主战役，实时推进并自动换季（每季5分钟）
- 建设、征募、研究、行军与军团整补使用统一真实时间队列：建设30秒、训练20秒、研究45秒、行军40秒、胜后整补90秒/战败整补120秒；支持倒计时、离线补算与幂等结算
- 知识资源与农业、军事、行政三条科技树；研究使用45秒全局队列，科技前置会限制高级研究、骑士征募和王冠谷攻城资格
- 春夏秋冬产出与消耗差异，冬季粮食压力；野战军补给成本高于城市驻军
- 金币、粮食、民心、军心、威望、王室认可与战争疲劳系统
- 7块相邻领地、3家敌对势力；王冠谷需控制6块领地、威望60、完成攻城工程并拥有80人第一军团后开放
- 地图数据扩展至36个城镇节点；首批战役仍在7座核心城运行，新增节点作为可视化战略位置
- 农田、集市、兵营、城墙四类三级建设
- 长矛兵、弓箭手、披甲骑士三类军队，以及不同军饷、军粮和战损顺序
- 平原、密林、山地、河网和王城地形克制；四季也会改变实际战力与补给
- 常例、轻徭、加税、军屯四类持续领地政策
- 征税、分类征兵、训练、休整、封赏、巡视与边防行动
- 7名统一写实风格核心人物立绘
- 人物五维（武力、统率、谋略、治理、魅力）、忠诚、野心、不满、功劳、负伤与领地管理
- 真实三阶段战役：接近敌军、正面交战、最后阶段；弓手轮射和骑士冲锋由实际军队配置解锁
- 出战人物根据能力提出不同战场方案
- 胜后可直接管理、交给家臣或允许村镇自治
- 敌方反攻、抢掠和领地易手
- 玩家第一军团拥有真实位置；只有位于敌城相邻领地、且完成整补的军团才能开战。行军使用MARCH队列，敌方势力也拥有资源、首都和军团，并通过真实行军发起袭扰
- 战役、人物事件采用Soft Pause；暂停期间不会产生换季时间债，恢复后会把暂停时长加回所有运行中的任务和换季时钟
- 征兵完成后先进入训练地驻军池，军团抵达当地且空闲时才能把驻军编入主力；不再使用全局兵池同步作战
- 征兵、训练、召见和出征不再受季度次数限制；征税和领地政策保留专用的季度锁，所有事件按Job完成时间、换季时间的真实顺序结算
- 敌方守军随年份和玩家扩张增长，战败会丢失随军金币和粮食；持续饥荒、重债和失去民心会触发崩溃
- 旧领主战败后的效忠、赎金或放逐
- 第一场冬天、继承权暗流、王室催税等事件
- 守信、强硬、经营三种实际统治风格与多结局
- 本地自动存档；无后端、无CDN、无数据上传
- V1旧版存档自动迁移至实时钟表、队列、科技与势力字段；兵种编成、领地政策和战争疲劳保持不变，不会凭空增减原有军队总数

## 启动

在本目录执行：

```bash
python3 -m http.server 8788
```

然后访问 `http://127.0.0.1:8788/`。

## 检查与封装

```bash
node --check app.js
node tests/structure.test.mjs
node tests/campaign-balance.sim.mjs
python3 build_single.py
```

打包后生成 `模拟中世纪领主-单文件版.html`，模块化源码不会被覆盖。

本游戏所有世界观、人物和势力均为原创架空设定。
