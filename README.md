# 模拟中世纪领主 · 铁冠之路

原创架空中世纪领主模拟游戏。玩家继承破败的渡鸦堡，通过四季经营、家臣政治和分阶段战争统一北境七领。

## 已实现

- 12年、48季度主战役，每季度3个行动点
- 春夏秋冬产出与消耗差异，冬季粮食压力
- 金币、粮食、民心、军心、威望、正统与战争疲劳系统
- 7块相邻领地、3家敌对势力与第7年开放的王冠谷终局
- 农田、集市、兵营、城墙四类三级建设
- 长矛兵、弓箭手、披甲骑士三类军队，以及不同军饷、军粮和战损顺序
- 平原、密林、山地、河网和王城地形克制；四季也会改变实际战力与补给
- 常例、轻徭、加税、军屯四类持续领地政策
- 征税、分类征兵、训练、休整、封赏、巡视与边防行动
- 7名统一写实风格核心人物立绘
- 人物五维、忠诚、野心、怨气、功勋、伤势与封地
- 真实三阶段战役：行军接敌、两军交锋、胜负将分；箭雨和骑士冲阵由实际编成解锁
- 随军人物根据能力提出不同战场方案
- 胜后可直辖、分封功臣或授予地方自治
- 敌方反攻、抢掠和领地易手
- 远征消耗2点行动，战后需整补2—3季；夺城会从野战军中留下驻军
- 敌方守军随年份和玩家扩张增长，战败会丢失辎重；持续饥荒、重债和失去民心会触发崩溃
- 旧领主战败后的效忠、赎金或放逐
- 第一场冬天、继承权暗流、王室催税等事件
- 守誓、铁腕、富国三种实际统治作风与多结局
- 本地自动存档；无后端、无CDN、无数据上传
- 旧版存档自动迁移兵种编成、领地政策和战争疲劳，不会凭空增减原有军队总数

## 启动

在本目录执行：

```bash
python3 -m http.server 8788
```

然后访问 `http://127.0.0.1:8788/`。

## 检查与封装

```bash
node --check app.js
node tests/structure.test.mjs
node tests/campaign-balance.sim.mjs
python3 build_single.py
```

打包后生成 `模拟中世纪领主-单文件版.html`，模块化源码不会被覆盖。

本游戏所有世界观、人物和势力均为原创架空设定。
